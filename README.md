# Harvard Interface

A small front-end project inspired by a Harvard-style academic dashboard. The goal of this project is to recreate a modern student portal interface using HTML, CSS, and JavaScript, while adding a few interactive behaviors to make the page feel more realistic.

## Overview

This project is a static web interface that includes:

- a left sidebar navigation menu
- a university-inspired header/logo section
- student and faculty cards
- academic summary tiles (ECTS, attendance, GPA)
- a search field to filter students by name
- simple JavaScript interactions for buttons and card updates

## Project Structure

- `index.html` — page structure and content
- `style.css` — styling, layout, colors, and responsive design
- `script.js` — interaction logic and search functionality
- `img/` — project images and icons

## Features

- Harvard-inspired color palette and layout
- Interactive side menu buttons
- Student cards displaying profile images, names, IDs, and departments
- Search functionality to filter student cards by name
- DOM-based interactions using JavaScript
- Lightweight static website: no framework or build step required

## How to Run

Because this is a simple static site, you can run it in two easy ways:

### Option 1: Open directly in the browser

Open `index.html` in your browser.

### Option 2: Serve it locally

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
